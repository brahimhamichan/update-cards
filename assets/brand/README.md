# Brand assets

The original Update Cards icon represents a stack of cards, a decision, and a clear next step. Blue `#315FE9` is the primary accent; ink `#101828` is the dark background.

- `icon.svg` — editable vector icon.
- `icon.png` — 256px skill icon.
- `social-preview.png` — 1280×640 repository sharing artwork. Upload it in GitHub's repository Settings → Social preview when preparing the public launch.
- `header.svg` — README artwork with its own background for light and dark GitHub themes. Its card is illustrative, not an interactive control.

Project artwork is covered by the root MIT license. These assets are distinct from the third-party demo logos in `../logos/`.
