# Sample artwork

These are hand-drawn, illustrative SVGs created for the update-cards demo examples (the video-walkthrough poster and the screenshot-proof before/after cards).
They contain no real product screenshots or implementation proof, and are released with this repository.
Each image carries an "Illustrative sample" label so it cannot be mistaken for real evidence.
The demo video example points at MDN's CC0 sample clip (https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4), which is a generic sample and not a recording of this project.
